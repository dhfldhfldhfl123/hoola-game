온라인 훌라: Node.js 18 이상에서 npm start 실행 후 http://localhost:3000 접속.
같은 Wi-Fi에서는 방화벽 허용 후 서버 PC의 내부 IP:3000으로 접속.
다른 집에서 접속하려면 Node.js 웹 서비스 호스팅에 이 폴더를 배포 (시작 명령 npm start). 발급된 HTTPS 주소 공유.
